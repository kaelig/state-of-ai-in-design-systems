# Do design systems serve agent skills from .well-known?

A few do: 3 of 19 systems reference a well-known skills endpoint —
[Nuxt UI](https://state-of-ai-in-design-systems.netlify.app/systems/nuxt-ui.md), [React Spectrum / Spectrum 2 (S2)](https://state-of-ai-in-design-systems.netlify.app/systems/react-spectrum-s2.md), [Nord Design System](https://state-of-ai-in-design-systems.netlify.app/systems/nord-design-system.md).

It is the newest distribution pattern in the dataset and the least settled: a year before this
snapshot it did not exist. The mainstream is still `npx skills add` or a skill bundled in the
system's CLI. If you are choosing today, publishing both costs little. Open those three records for
